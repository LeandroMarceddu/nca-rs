# bare-file

Proves the zero-config path: no comments, no tool data, no stock, no machine.
The program opens, renders, simulates with a labeled centerline cutter, runs
every rule that needs no setup, and lists each skipped rule with its missing
input.

Golden draft: the current three-rule registry evaluates two rules; machine
limits are missing, so `travel.machine_envelope` is skipped with `machine`.
The draft is pending review.
