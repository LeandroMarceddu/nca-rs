# Fixtures

Fixture folders live under `fixtures/`:

```text
fixtures/
  synthetic/<name>/{source.nc,config.toml,expected.json,NOTES.md}
  real/<name>/{source.nc,config.toml,expected.json,NOTES.md}
```

Rules:

- `source.nc` is the complete program; never truncate it silently.
- `config.toml` uses the schema in `docs/INTERFACES.md`. Omit tables you do not
  need; an omitted `[stock]` means inferred stock.
- `expected.json` is the full golden report, reviewed by the orchestrator before
  it is committed.
- `NOTES.md` states what the fixture proves, which post/machine produced it, and
  the permission for any real file.

See `docs/FIXTURES.md` for the required synthetic coverage and the review
process.

## Draft goldens

The `expected.json` files under `fixtures/synthetic/` were generated by the
current three-rule vertical slice (`modal.feed_missing`,
`travel.machine_envelope`, `clearance.rapid_at_depth`) and are drafts pending
orchestrator review. `parse.unsupported` findings are emitted from lossy parser
skips, but that catalog rule is not in the registry yet, so those findings are
outside the `coverage` counts. A fixture whose intended rule is not implemented
still has a golden with fewer diagnostics; the individual `NOTES.md` files call
that out where it matters.
